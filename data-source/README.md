# Sumber data primer

`UUD-NRI-1945-Dalam-Satu-Naskah.pdf` adalah naskah Undang-Undang Dasar Negara Republik Indonesia Tahun 1945 "Dalam Satu Naskah" yang diterbitkan Sekretariat Jenderal Majelis Permusyawaratan Rakyat RI (salinan yang dimuat di jdih.bapeten.go.id, 49 halaman). Hash SHA-256 ada di `SHA256SUMS.txt`.

Seluruh teks pasal di dalam game (`src/data/uud-1945.json`) diekstraksi dari berkas ini oleh `scripts/build-uud1945.py`. Tidak ada teks pasal yang diketik ulang atau dikarang. Penanda amandemen `1)`–`4)` pada naskah dipetakan ke Perubahan Pertama sampai Keempat.
