# Pasal Frenzy

Permainan 3D tentang Undang-Undang Dasar Negara Republik Indonesia Tahun 1945. Pemain merangkai teks Pembukaan di ruang hampa, lalu mempertahankan integritas konstitusional dalam tiga kasus.

_A 3D game about the 1945 Constitution of the Republic of Indonesia._

- Situs: https://fashich.github.io/Pasal-Frenzy/
- Unduh: [GitHub Releases](https://github.com/Fashich/Pasal-Frenzy/releases/latest)
  - **Windows** (installer `.exe`, Windows 10/11 64-bit). Jika muncul "Windows melindungi PC Anda", pilih Info selengkapnya → Tetap jalankan.
  - **Android** (paket `.apk`, Android 9 ke atas). Izinkan pemasangan dari sumber tidak dikenal.
- Lapor masalah atau beri saran: [Issues](https://github.com/Fashich/Pasal-Frenzy/issues/new)

## Isi repositori

Repositori ini berisi situs Pasal Frenzy (Landing dan halaman Dukungan) yang disajikan lewat GitHub Pages, beserta berkas rilis aplikasi. Berkas situs adalah hasil build; jangan diubah langsung di sini.

## Teks konstitusi

Teks UUD NRI 1945 di dalam permainan diambil dari naskah resmi MPR RI "UUD NRI 1945 Dalam Satu Naskah" tanpa perubahan, lalu diperiksa ulang secara otomatis:

- [Laporan ekstraksi dan validasi naskah](docs/data-validation/uud-1945-report.md)
- [Laporan verifikasi teks yang dipakai permainan](docs/data-validation/teks-game-report.md)
