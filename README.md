# Pasal Frenzy

Permainan web tiga dimensi tentang Undang-Undang Dasar Negara Republik Indonesia Tahun 1945. Pemain merangkai teks Pembukaan di ruang hampa, lalu mempertahankan integritas konstitusional dalam tiga kasus: benturan HAM dan keamanan negara (Pasal 28A–28J), oligarki digital dan Pasal 33, serta penyalahgunaan Perppu (Pasal 22).

Status: dalam pengembangan menuju MVP v1.0.0. Dokumen rancangan ada di `docs/`, sumber teks konstitusi ada di `data-source/`.

Teks pasal diambil dari naskah resmi MPR RI "UUD NRI 1945 Dalam Satu Naskah" tanpa perubahan.
